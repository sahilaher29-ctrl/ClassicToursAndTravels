# Classic Tours And Travels 🚗

A modern cab booking and sightseeing website for exploring Lonavala and Khandala.

## 🌐 Project Overview

Classic Tours And Travels is a full-stack tourism and cab booking web application designed to help customers explore sightseeing destinations and book cabs conveniently.

The website provides cab packages, sightseeing information, vehicle selection, dynamic pricing, booking forms, and WhatsApp booking integration.

## ✨ Features

- 🚗 Cab booking system
- 📦 Multiple tour packages
- 👥 Passenger selection
- 🚘 4-seater and 7-seater vehicle options
- 📅 Weekday and weekend pricing
- 📍 Pickup location selection
- 🏞️ Lonavala & Khandala sightseeing destinations
- 🖼️ Sightseeing images and destination details
- 📱 Responsive design for mobile and desktop
- 💬 WhatsApp booking integration
- 📝 Customer booking form
- 💰 Dynamic package pricing
- 🔗 GitHub version control
